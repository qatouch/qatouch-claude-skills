# Security Policy

## Supported Versions

We provide security updates for the latest released version of this repository
and its published skills. Older versions are supported at the discretion of the
maintainers.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than
opening a public issue.

1. Email the maintainers at **security@qatouch.com** with a description of the
   issue, affected files or skills, and steps to reproduce.
2. Do not disclose the vulnerability publicly until a fix has been released.
3. We will acknowledge receipt within 3 business days.
4. We will work with you to understand and resolve the issue, and will credit
   reporters who wish to be acknowledged.

## Responsible Disclosure

We follow a coordinated disclosure process:

- We aim to release a fix within 30 days of a confirmed report for high severity
  issues.
- Once a fix is published, a summary may be shared in the `CHANGELOG.md`.
- Please do not include sensitive data such as credentials or tokens in your
  report.
